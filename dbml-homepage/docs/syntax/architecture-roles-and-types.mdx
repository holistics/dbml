# Roles and Types

This page lists the 32 built-in roles and all values of the `type` setting in [System Architecture](./system-architecture.md). For how an element gets its icon, see [Element Icon](./system-architecture.md#element-icon).

## Roles

The roles are listed in the order [Role Precedence](./system-architecture.md#role-precedence) uses.

## Types

The `type` setting takes one of these values, such as `type: 'postgres'`. Values are case-insensitive. Values listed after "also" on a card give the same icon. For example, `'postgresql'` gives the same icon as `'postgres'`.

A value not on this list gives a warning, which suggests close values when there are any.

Type icons are shown here in the text color. An element's type icon takes the color of its role's category, or the element's `color` when it has one.
